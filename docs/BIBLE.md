# Bible

`/bible` in the Reader (public, no sign-in). Menu item "Bible" (sidebar and bottom bar).

## What ships
- **KJV** (public domain) with Strong's numbers, **words of Jesus in red** (from the OSIS `who="Jesus"` markup), tap-a-word Strong's dictionary (Hebrew + Greek), **cross-references** (tap a verse number) and a **concordance** (search any word, or every verse that uses one Strong's number).
- Data lives in `public/bible/` and is generated by `python3 scripts/build-bible.py <source dir>` (sources: scrollmapper/bible_databases `KJV-osis.json` and `cross_references.txt`, openscriptures/strongs dictionaries). It is committed, so no build step is needed on the server.
- Search API: `GET /api/bible/search?q=word` or `?strong=G26` (reads `public/bible/kjv/*.json`, cached in memory).

## Credits (shown on the page)
KJV + Strong's tagging: CrossWire/OpenScriptures. Strong's dictionary: OpenScriptures, CC-BY-SA. Cross-references: openbible.info, CC-BY.

## NIV, AMP and MSG (API.Bible)
Fetched live from API.Bible by `GET /api/bible/chapter?version=NIV&book=43&chapter=3` using `BIBLE_API_KEY` (server `.env`, never committed). Words of Jesus are red for NIV and AMP; the publisher of MSG does not mark them. Cross-references work for every version (by verse number); Strong's and the concordance are KJV-only. The page loads API.Bible's usage-report script (`pkg.api.bible/fumsV3.min.js`, "FUMS") and shows each version's copyright line, as their terms require.
- The free Starter plan covers up to 3 licensed Bibles for **non-commercial** use and 5,000 requests a month. Ebookvox has ads and subscriptions, so move to a paid plan and check each publisher's terms before relying on this commercially.
- Which versions the key can read: `curl -H "api-key: $BIBLE_API_KEY" https://rest.api.bible/v1/bibles`. To switch another on, add its `apiId` in `src/lib/bible.ts`.

## YouVersion Platform (BSB, WEB, TPT)
Same route, `YOUVERSION_APP_KEY` in the server `.env` (sent as `X-YVP-App-Key` to `api.youversion.com`). BSB and WEB (public domain, red letters) work now. The key's licensed list is only open-licence Bibles; NIV, AMP, NASB and TPT show as "unlockable" until their publisher licence is accepted in the platform portal (https://platform.youversion.com). Once TPT is accepted, set `available: true` for it in `src/lib/bible.ts`. Check what a key can read: `curl -H "X-YVP-App-Key: $KEY" "https://api.youversion.com/v1/bibles?language_ranges[]=en&all_available=true"`. Copyright lines come from each Bible's metadata and must stay visible. Terms for commercial use are not public: read each Bible's licence in the portal.
